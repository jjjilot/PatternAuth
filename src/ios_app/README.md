# Ios App Installation Instructions

1. Ensure Ios device is connected to machine through wired connection and Xcode is downloaded on machine.
2. Open the PatternAuth-Xcode directory in Xcode. (This directory is found in the ios_app directory). This can be most simply accomplished by opening Xcode, then clicking on the PatternAuth-Xcode directory and dragging it on top of the Xcode app icon.
3. Change the run destination to your Ios device by using the run destination menu at the top of the screen.
4. Unlock your Ios device and click the "play" button in the top left of the screen: this will build the app on your device. *Note: If this is your first time building an app on this device, it will prompt you to trust the developer and fail the build. Apple provides instructions for this procedure: Open Settings on the device and navigate to General -> VPN & Device Management, then select your Developer App certificate to trust it. After the device trusts you as a developer attempt the build again*

5. The PatternAuth app is now downloaded on your device! To use all app functionality you must also allow it to access FaceID when prompted.
